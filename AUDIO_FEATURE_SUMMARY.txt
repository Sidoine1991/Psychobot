WHAT'S HAPPENING TECHNICALLY
══════════════════════════════════════════════════════════════════════════

  1. RECEPTION:
     - Baileys (WhatsApp library) receives audio message
     - Handler detects messageType as 'voice_note' or 'audio'
     - Checks conversation state (don't reply if owner active)

  2. DOWNLOAD & CONVERT:
     - Extract audioMessage.mediaKey
     - Download OGG audio from WhatsApp servers
     - Convert OGG Opus → WAV 16kHz (required for Whisper)

  3. TRANSCRIPTION:
     - Send WAV file to OpenAI Whisper API
     - Receive text transcript back
     - Auto-detect French vs English

  4. AI GENERATION:
     - Pass transcript to NVIDIA NIM (Llama 3.3 70B)
     - Get conversational AI response
     - Store in conversation history

  5. TEXT-TO-SPEECH:
     - Send response text to Google TTS
     - Receive MP3 audio URL
     - Download MP3 file

  6. FORMAT CONVERSION:
     - Use FFmpeg to convert MP3 → OGG Opus
     - Match WhatsApp voice note format
     - Cleanup temp files

  7. DELIVERY:
     - Send audio reply to user (OGG format)
     - Also send text summary (transcript + response)
     - Mark original message as read
